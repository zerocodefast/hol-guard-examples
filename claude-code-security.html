Claude Code Security

Protect Anthropic's Claude Code from malicious plugins and supply chain attacks.

Claude Code runs with full shell access to your codebase, environment variables, and system commands. A single malicious plugin can exfiltrate secrets, modify code, or execute arbitrary commands.

Why Claude Code Needs Security Scanning

Claude Code supports MCP servers and custom plugins that extend its capabilities. These plugins run in the same process as your AI agent with access to:

  • Your entire codebase
  • Environment variables and .env files
  • Shell execution privileges
  • Network access

A compromised plugin can read API keys, inject backdoors, or exfiltrate proprietary code to remote servers.

How HOL Guard Protects Claude Code

🔍 Plugin Scanning

Scan every MCP server and plugin before installation. Checks for hardcoded secrets, dangerous commands (rm, sudo, eval), and insecure configurations.

plugin-scanner scan /path/to/plugin --format text

🛡️ Runtime Protection

4 protection levels from Gentle (minimal friction) to Paranoid (every operation verified). Intercepts malicious actions in real-time.

⚡ CI Integration

GitHub Action that runs on every PR. Fails the build if score < 80 or any high/critical findings.

uses: hashgraph-online/ai-plugin-scanner-action@v1

Getting Started

  1. Install the scanner: pipx install plugin-scanner
  2. Scan your current Claude Code plugins: plugin-scanner scan ~/.claude/plugins --format text
  3. Add CI to your custom plugins
  4. Set protection level in HOL Guard
