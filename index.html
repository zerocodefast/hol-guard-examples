What is HOL Guard?

HOL Guard is an open-source (Apache 2.0) security scanner that protects AI coding agents from malicious plugins, hardcoded secrets, and supply-chain risks. It works with Claude Code, OpenAI Codex, Cursor, Gemini, OpenCode, and any tool that uses MCP servers or plugins.

Quick Start

Scan your plugin

plugin-scanner scan . --format text

Quick lint

plugin-scanner lint . --format text

Verify marketplace readiness

plugin-scanner verify . --format text

JSON output for CI

plugin-scanner scan . --format json --output report.json

SARIF for GitHub Advanced Security

plugin-scanner scan . --format sarif --output results.sarif

Protection Levels

HOL Guard offers 4 preset protection levels for different risk appetites:

🌿 Gentle

Minimal friction. Checks for obvious issues only. Best for rapid development.

⚖️ Balanced

Standard security checks. Recommended for most projects. The default.

🔒 Strict

Comprehensive scanning. No high-severity findings allowed. Best for shared/public plugins.

🛡️ Paranoid

Maximum security. Every finding is a blocker. Best for financial, medical, or enterprise use.

CI Integration

Add a security gate to every PR with the official GitHub Action:

name: HOL Plugin Scanner

on:
  push:
    branches: [main, master]
  pull_request:
    branches: [main, master]

permissions:
  contents: read
  security-events: write

jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683

      - name: HOL Plugin Scanner
        uses: hashgraph-online/ai-plugin-scanner-action@v1
        with:
          plugin_dir: "."
          mode: scan
          min_score: 80
          fail_on_severity: high
          format: sarif
          upload_sarif: true

Why This Matters

AI coding agents run with full shell access. A malicious plugin can read your environment, exfiltrate code, or execute arbitrary commands. HOL Guard is the first line of defense — catching issues before they reach your agent.

Real threats the scanner catches:

  • Hardcoded API keys and tokens in plugin files
  • Dangerous MCP commands (rm -rf, sudo, curl | sh)
  • Unpinned GitHub Actions (supply chain risk)
  • Missing security policies or licenses
  • Eval() and shell injection in skill code
  • Insecure MCP server configurations

Cisco AI Defense Integration

HOL Guard integrates with Cisco AI Defense for enterprise-grade scanning. The Cisco skill scanner and MCP scanner run as additional layers, catching threats that static analysis alone misses.

Trust Registry

Verified plugins are listed on the HOL Plugin Registry with a trust score. Users can browse and install plugins with confidence.
