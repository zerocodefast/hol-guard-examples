What is HOL Guard?

HOL Guard is an open-source (Apache 2.0) security framework built by Hashgraph Online. It protects AI coding agents from malicious plugins, supply-chain attacks, and hardcoded secrets.

It works with Claude Code, OpenAI Codex, Cursor, Gemini, OpenCode, and any tool that uses MCP servers or plugins.

Why AI Agent Security Matters

AI coding agents run with full shell access to your codebase, environment variables, and infrastructure. A single malicious plugin can:

  • Read your .env files and exfiltrate API keys
  • Execute arbitrary commands via eval() or shell injection
  • Modify your source code to introduce backdoors
  • Exfiltrate proprietary code to remote servers
  • Run rm -rf or cryptocurrency miners

HOL Guard is the first line of defense — scanning every plugin before it reaches your agent.

What HOL Guard Provides

🔍 Plugin Scanner

Static analysis tool that scores plugins on a 130-point scale across 7 security categories. Catches secrets, dangerous MCP commands, and supply-chain risks.

PyPI: plugin-scanner

🛡️ CI Integration

GitHub Action that runs on every PR. Fails the build if score < 80 or any critical/high findings. Uploads SARIF to GitHub Advanced Security.

GitHub Action

⚡ Real-Time Agent Shield

Runtime protection for AI agents with 4 protection levels: Gentle, Balanced, Strict, and Paranoid. Intercepts malicious operations as they happen.

🤝 Cisco AI Defense

Enterprise-grade integration with Cisco AI Defense. Deep skill scanning and MCP server analysis for corporate deployments.

Quick Start

Scan a plugin

plugin-scanner scan /path/to/your-plugin --format text

Quick lint (faster, fewer checks)

plugin-scanner lint /path/to/your-plugin --format text

Verify marketplace readiness

plugin-scanner verify /path/to/your-plugin --format text

JSON output for CI

plugin-scanner scan /path/to/your-plugin --format json --output report.json

SARIF for GitHub Advanced Security

plugin-scanner scan /path/to/your-plugin --format sarif --output results.sarif

Operational Security20Pinned Actions, no write-all, Dependabot, lockfiles
Best Practices15README.md, skills directory, SKILL.md frontmatter, .codexignore
Marketplace15marketplace.json valid, safe source paths
Skill Security15Cisco scan clean, no elevated findings, analyzable
Code Quality10No eval/new Function, no shell injection

Passing threshold: 80+ points with no critical or high severity findings.

Protection Levels

🌿 Gentle

Minimal friction. Checks for obvious issues only. Best for rapid development and prototyping.

⚖️ Balanced

Standard security checks. Recommended for most projects. This is the default.

🔒 Strict

Comprehensive scanning. No high-severity findings allowed. Best for shared or public plugins.

🛡️ Paranoid

Maximum security. Every finding is a blocker. Best for financial, medical, or enterprise use.

Add CI to Your Plugin

Copy this workflow into .github/workflows/hol-guard.yml:

name: HOL Guard Plugin Scan

on:
  push:
    branches: [main, master]
  pull_request:
    branches: [main, master]

permissions:
  contents: read
  security-events: write

jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683

      - name: Run HOL Plugin Scanner
        uses: hashgraph-online/ai-plugin-scanner-action@v1
        with:
          plugin_dir: "."
          mode: scan
          min_score: 80
          fail_on_severity: high
          format: sarif
          upload_sarif: true

      - name: Upload SARIF
        uses: github/codeql-action/upload-sarif@v3
        if: always()
        with:
          sarif_file: results.sarif

Trust Registry

Verified plugins are listed on the HOL Plugin Registry with a trust score. Users can browse and install plugins with confidence.

The Awesome Codex Plugins list now requires HOL Guard scanning for inclusion. Plugin authors must pass the scanner to be listed.
