HOL Plugin Scanner Reference

Complete scoring system: 7 categories, 130 points total.

The HOL Plugin Scanner evaluates plugins across 7 categories. Each category has a maximum score. A plugin needs 80+ points with no critical or high severity findings to pass.

Score Breakdown

CategoryMaxWhat It Checks
Manifest Validation31Valid plugin.json, required fields, semver, kebab-case ID
Security36SECURITY.md, LICENSE, no secrets, hardened MCP remotes
Operational Security20Pinned Actions, no write-all, Dependabot, lockfiles
Best Practices15README.md, skills directory, SKILL.md frontmatter, .codexignore
Marketplace15marketplace.json valid, safe source paths
Skill Security15Cisco scan clean, no elevated findings, analyzable
Code Quality10No eval/new Function, no shell injection

Total: 130 points | Passing: 80+ | Must have: no critical or high findings

Manifest Validation (31 points)

What It Checks

  • plugin.json is valid JSON
  • All required fields present (id, name, version, description, author)
  • Version follows semver
  • ID uses kebab-case
  • Repository URL is valid

Security (36 points)

What It Checks

  • SECURITY.md exists with supported versions and reporting policy
  • LICENSE exists (Apache 2.0, MIT, etc.)
  • No hardcoded secrets (API keys, tokens, passwords)
  • No private keys in repo
  • MCP remotes are hardened (no http, validated)

Operational Security (20 points)

What It Checks

  • GitHub Actions are pinned to commit hashes
  • No overly permissive permissions (e.g., write-all)
  • Dependabot is configured
  • Package lockfiles exist

Best Practices (15 points)

What It Checks

  • README.md exists with clear description
  • skills/ directory exists
  • SKILL.md has proper frontmatter
  • .codexignore file exists

Marketplace (15 points)

What It Checks

  • marketplace.json is valid
  • Source paths are safe (no .., no absolute paths)
  • Dependencies are reasonable

Skill Security (15 points)

What It Checks

  • Cisco scan is clean
  • No elevated findings
  • Skill code is analyzable (not obfuscated)

Code Quality (10 points)

What It Checks

  • No eval() or new Function() calls
  • No shell injection vulnerabilities
  • No dangerous child_process usage

Running the Scanner

plugin-scanner scan /path/to/plugin --format text
plugin-scanner scan /path/to/plugin --format json --output report.json
plugin-scanner scan /path/to/plugin --format sarif --output results.sarif
plugin-scanner lint /path/to/plugin --format text
plugin-scanner verify /path/to/plugin --format text
