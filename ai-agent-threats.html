AI Agent Security Threats 2026

Real threats targeting AI coding agents and how to defend against them.

AI coding agents have full access to your codebase, environment, and shell. This makes them a high-value target for attackers. Here are the threats you need to know about.

Threat 1: Malicious Plugin Supply Chain

Attackers publish plugins that look legitimate but contain backdoors. Because AI agents install and execute plugins automatically, the malicious code runs before anyone reviews it.

Defense: Scan every plugin before installation with plugin-scanner scan . --format text. HOL Guard checks for hardcoded secrets, dangerous commands, and insecure configurations.

Threat 2: Hardcoded Secrets in Plugins

Plugins that contain hardcoded API keys, database passwords, or tokens. Even if the plugin itself is not malicious, these secrets leak into your codebase and can be exfiltrated.

Defense: HOL Guard's Security category (36 points) checks for secrets, evaluates the presence of a SECURITY.md, and verifies the LICENSE.

Threat 3: Dangerous MCP Server Commands

MCP servers can execute arbitrary commands via child_process, eval(), or shell execution. A compromised MCP server can delete files, install malware, or exfiltrate data.

Defense: HOL Guard scans for dangerous patterns like rm -rf, sudo, curl | sh, and eval() in plugin code. The Code Quality category (10 points) catches these.

Threat 4: Unpinned CI Dependencies

Plugins that use GitHub Actions without pinned commit hashes are vulnerable to supply chain attacks. If the upstream action is compromised, your plugin build is compromised.

Defense: HOL Guard's Operational Security category (20 points) checks for pinned Actions, Dependabot configuration, and lockfiles.

Threat 5: Missing Security Policy

Plugins without a SECURITY.md or license create legal and operational risks. If a vulnerability is found, there is no clear process for reporting or fixing it.

Defense: HOL Guard requires SECURITY.md and LICENSE for full points. The HOL Guard template repo includes these files by default.

Getting Protected

pipx install plugin-scanner
plugin-scanner scan /path/to/your-plugin --format text

Or add CI to your plugin repo:

uses: hashgraph-online/ai-plugin-scanner-action@v1
