How to Scan AI Plugins

From zero to secure in 5 minutes. Step-by-step guide.

Step 1: Install the Scanner

Install via pipx (recommended) or pip:

pipx install plugin-scanner

# Or with pip
pip install plugin-scanner

Step 2: Run Your First Scan

Point the scanner at any plugin directory:

plugin-scanner scan /path/to/your-plugin --format text

Example output:

Scanning: /path/to/your-plugin
Manifest: 27/31 points
Security: 32/36 points
Operational: 18/20 points
Best Practices: 14/15 points
Marketplace: 12/15 points
Skill Security: 15/15 points
Code Quality: 10/10 points

Total: 118/130 points
Passed: Yes (score ≥ 80, no critical/high findings)

Step 3: Fix Findings

If the scan fails, address the findings:

  • Missing SECURITY.md? Add one from the template.
  • Hardcoded secrets? Move them to environment variables.
  • Dangerous commands? Refactor to remove eval(), shell exec, etc.
  • Unpinned Actions? Update to commit SHA references.

Step 4: Add CI (Optional)

Automate scanning on every PR with the GitHub Action:

uses: hashgraph-online/ai-plugin-scanner-action@v1

This fails the build if score drops below 80 or critical/high findings appear.

Step 5: Choose Protection Level

HOL Guard Agent Shield runs at 4 levels:

  • Gentle: Minimal checks — rapid development
  • Balanced: Standard checks — recommended for most users
  • Strict: No high-severity findings allowed — public/shared plugins
  • Paranoid: Every finding is a blocker — enterprise/sensitive code
