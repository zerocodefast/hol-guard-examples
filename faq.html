HOL Guard FAQ

Frequently asked questions about AI agent security and HOL Guard.

What is HOL Guard?

HOL Guard is an open-source security scanner for AI coding agents (Claude Code, OpenAI Codex, Cursor, etc.). It checks plugins, skills, and MCP servers for vulnerabilities before they get installed or published.

What does HOL Guard scan for?

7 categories of checks: manifest validation, security (secrets, policies), operational security (CI/CD), best practices, marketplace compliance, skill security, and code quality. Total of 130 points. You need 80+ to pass.

Does HOL Guard run on my code or just the plugin?

It scans the plugin or skill directory you point it at. It does not modify your code or send it anywhere. Everything runs locally.

Is HOL Guard free?

Yes. HOL Guard is open source under Apache 2.0. The scanner (plugin-scanner) is available on PyPI. The GitHub Action is free to use.

What is the HOL Plugin Scanner?

The HOL Plugin Scanner is the CLI tool that runs the actual security checks. Install it via pipx install plugin-scanner or pip install plugin-scanner. It's the core engine behind HOL Guard.

What AI agents does HOL Guard support?

Any agent that uses plugins with a plugin.json manifest or MCP servers. Specifically tested with Claude Code, OpenAI Codex, Cursor, and Gemini. The scanner checks the plugin structure, not the agent itself.

What is a passing score?

80+ out of 130 points, with no critical or high severity findings. The score is broken into 7 categories, so a plugin can be strong in some areas and weak in others.

What are the protection levels?

HOL Guard Agent Shield has 4 levels: Gentle (minimal checks), Balanced (standard, recommended), Strict (no high findings allowed), and Paranoid (every finding is a blocker). You can set the level per project.

Can I use HOL Guard in CI/CD?

Yes. The official GitHub Action (hashgraph-online/ai-plugin-scanner-action@v1) runs on every PR and fails the build if the score is below 80 or critical/high findings are present. You can also run it in any CI system that supports Python.

Who built HOL Guard?

HOL Guard is built by Hashgraph Online, a team focused on open-source AI infrastructure and security. The project is community-driven and accepts contributions.
