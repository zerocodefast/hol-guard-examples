OpenAI Codex Security

Secure OpenAI Codex from malicious plugins and supply chain attacks.

OpenAI Codex is a coding agent that operates directly on your codebase. It can execute shell commands, read files, and install plugins via MCP servers. This level of access makes it a high-value target for supply chain attacks.

Why Codex Needs Security Scanning

  • Plugins run with the same permissions as the Codex process
  • MCP servers can execute arbitrary code on your machine
  • Custom skills can read environment variables and secrets
  • Third-party plugins are often installed without review

Scanning Codex Plugins with HOL Guard

plugin-scanner scan ~/.codex/plugins --format text

Or scan a specific plugin before installing:

plugin-scanner scan /path/to/plugin --format json

Protection Levels for Codex

Gentle

Minimal checks for rapid development. Good for trusted, internal plugins.

Balanced (Default)

Standard security checks. Recommended for most Codex users.

Strict

No high-severity findings allowed. Use for public or shared plugins.

Paranoid

Every finding is a blocker. Use for enterprise or sensitive codebases.
