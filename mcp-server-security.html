MCP Server Security

How to scan, validate, and secure Model Context Protocol servers before they access your codebase.

The Model Context Protocol (MCP) allows AI agents to connect to external tools, databases, and APIs. An MCP server runs with the same privileges as your AI agent — full shell access, network access, and filesystem access.

Why MCP Servers Are High-Risk

Unlike traditional APIs, MCP servers:

  • Run as local processes with your user's permissions
  • Can execute arbitrary code via eval(), child_process, or shell commands
  • Read environment variables containing API keys and database credentials
  • Are often installed from unverified sources

A malicious MCP server can exfiltrate your entire codebase, delete files, or install persistent backdoors.

Scan an MCP Server with HOL Guard

plugin-scanner scan /path/to/mcp-server --format text

The scanner produces a 130-point score across 7 categories:

  • Manifest Validation (31 pts) — valid plugin.json, required fields, semver
  • Security (36 pts) — SECURITY.md, LICENSE, no secrets
  • Operational Security (20 pts) — pinned Actions, Dependabot
  • Best Practices (15 pts) — README, skills directory, SKILL.md
  • Marketplace (15 pts) — marketplace.json, safe paths
  • Skill Security (15 pts) — no elevated findings
  • Code Quality (10 pts) — no eval/new Function, no shell injection

Passing: 80+ points with no critical or high severity findings.

Adding CI to MCP Server Repos

Add this workflow to .github/workflows/hol-guard.yml in your MCP server repository:

name: MCP Server Security Scan

on:
  push:
    branches: [main, master]
  pull_request:
    branches: [main, master]

permissions:
  contents: read
  security-events: write

jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683

      - name: HOL MCP Server Scan
        uses: hashgraph-online/ai-plugin-scanner-action@v1
        with:
          plugin_dir: "."
          mode: scan
          min_score: 80
          fail_on_severity: high
          format: sarif
          upload_sarif: true
